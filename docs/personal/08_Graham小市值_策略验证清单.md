# Graham小市值：Panel策略验证清单

已安装三组自定义策略。进入「回测 → 策略回测」，选择策略，点击「使用100万·20槽·日线基线」，再开始回测。已有工程核验可从「回测历史」恢复。

| 策略 | 作用与入选规则 |
|---|---|
| S0 纯小市值对照〔月调研究〕 | 历史总市值最小20只，用来判断改善是否只是小盘行情带来的。 |
| S1 Graham净流动资产〔月调研究〕 | 总市值≤NCAV的2/3，按NCAV/市值排序。NCAV扣总负债及非负少数股东权益；默认未扣缺失的优先权益，属于近似研究版。开启“严格优先权益”后，缺字段不入选。 |
| S2 小市值价值质量〔月调研究〕 | 最小20%市值中，归母利润TTM与经营现金流TTM均为正，负债率≤60%；按规模40%＋E/P40%＋ROA20%排名。它是价值质量增强，不等于已经验证成长性。 |

三组统一：沪深、上市满252交易日、历史名称排除ST及退市标签、当时非金融报表、20日均成交额至少2000万元；月末收盘选前20，下一交易日开盘调至每槽5%，缺槽留现金。未成交买单当天取消，完整退出受阻继续等待；保留股按月调整。无额外择时、止损覆盖或自动寻优。

## 只检查这七项

- [ ] **同口径对照**：三组用同一时段、本金100万、20槽、共用资金账户、日线及次日开盘。先保留原始结果，再修改参数。
- [ ] **先看能否承受亏损**：记录最大回撤、最长恢复期、最差年度／月份、平均仓位，再看年化收益。先写下自己可承受的回撤上限；年化50%是目标，不是通过标准。完整三组同口径长样本尚未验收。
- [ ] **抽查10笔**：随机抽5笔和最大亏损5笔，点开K线，核对月末信号、实际成交日、排名、历史市值、NCAV或E/P与ROA、报告期及公告日。财务只允许公告日早于信号日。胜负归因是规则解释，不能当作因果证明。
- [ ] **核对账户曲线**：每天“现金＋持仓市值＋应收权益＝净值”；收益和回撤图包含空仓日。没有成交时保持现金；期末未卖出只估值，不能计成已平仓胜率。
- [ ] **核对交易约束**：涨跌停开盘不假设排队成功，停牌不成交，次日执行、最低佣金5元、历史印花税及过户费，单日成交额不超过信号日20日均额的1%。科创板最低200股、1股递增；未建清算账本的持仓退市报错，不沿用旧价掩盖损失。
- [ ] **压力与样本外**：滑点10bp与30bp各跑一份；把已有2023年以来数据按时间分成研究段、验证段，规则只在研究段确定，固定后验证段只验一次。补足更早熊市后再谈跨周期稳健性，不能反复看验证段调参。
- [ ] **保存复现**：退出并重进页面，从历史恢复曲线、交易清单及原始参数；确认输入SHA256与严格优先权益选项一致。同一输入同一配置应得到同一交易和净值。

## K线怎么读

沿用Panel的空心红涨、实心青绿跌，以及买点在图下、卖点在图上的布局。空心菱形是信号，实心成交标记是实际执行；月度减仓标“恢复目标权重”，未入选退出单独标注。期末估值不画卖出成交。

图下展示财报与排名快照、规模／价值／质量分数贡献、真实买入／加仓价与数量；单笔展示价格及费用、分红净额。K线为Panel复权价，成交价为原始价，避免把二者混画为同一价格水平。信号未成交的原因计数见结果的execution字段；完整目标名单、现金流水及成交保存在研究目录。
