# 红利增强：本地日频研究版

原文件为 `strategy/joinquant/红利增强.py`。只记录原文件哈希，不执行、复制或导入其中的聚宽平台代码。用户已选择先研究可独立复现的日频核心。

## 核心思路

每月两路选股：低 Beta 路线先选股息率前10%且超过3%，在其中取 Beta 较低的一半，再取1或4只。价值路线先筛 PE、扣非ROE、收入与利润增长，再选高股息前10%且超过3%，取4或1只。沪深300完成月线 MACD 为正时，两路数量为1+4；否则4+1。合并去重后通常不超过5只。

月末收盘生成目标，下个交易日开盘执行。保留仍在目标中的旧仓；只有新股票按调仓前净资产÷去重目标数分配资金，并非每月重置全部持仓权重。原版默认关闭的止损、动量、三年分红和熊市降仓保持关闭。

## 独立版本与明确差异

看板入口 `custom_dividend_enhanced_daily_local`，名称 **红利增强〔日频本地口径·非原版〕**。对应严格核对入口 `custom_dividend_enhanced_strict` 会拒绝生成收益。

- 本地 Beta 固定为252个交易日相对沪深300日收益的 OLS 系数，不能声称等于平台 beta。
- 财务使用本地已公告累计扣非ROE、累计总营收同比和累计净利润同比，不能声称等于原版单季度字段。PE范围8—50，扣非ROE和营收同比5—100，净利润同比10—100。
- 股息率回溯365自然日内已除息的现金派息，以登记日历史总股本估算派息总额，再除以信号日历史总市值。原版按登记日窗口，二者边界不同；多股类的实际分红基数尚未完全核验。
- 关闭昨日涨停保护、11点开板交易与511880分支。未投资金留现金，收益按零计算。日线最高/最低不用于猜测盘中订单。
- 原版 set 的随机迭代顺序改为低Beta路线优先、再按路线排序及代码打破并列，保证现金不足时仍可重复。

这些差异冻结在代码 SPEC、安装目录 `dividend_inputs/resolved_spec.json` 和每次结果的规则快照中，不允许把两种版本混称。

## 防止未来信息与资金错账

财务只用公告日期严格早于信号日的版本，每期先取当时版本再选最新报告期；月线只用由完整日历确认的完成月份，并要求至少34个月。历史市值、登记日股本、历史名称均按日期读取。扫描与回测共用同一候选函数。

成交只读实际开盘与当日涨跌停基准，不用当日收盘、高低点或全天量审批开盘订单；停牌/限价时明确拒单，不买候补。原始价格负责现金和股数，分红与送转独立入账，应收与可用现金分开。佣金最低5元，印花税和过户费按历史分界，滑点显式计费；现金分红永久预留20%税是保守研究情景，不等于券商最终税单。期末持仓只估值，不伪造成交。

同一分红事件金额冲突、登记日股本缺失时，整只股票在该信号日排除并输出原因，不取最大、不双算、不用最新股本回填。必要整表缺失、月线不足、指数缺失、已知退市持仓无清算规则或无法解释的除权会中止。本轮尚未证明供应商财报版本、历史ST和退市整理名单完全无遗漏，因此不宣称已经消除全部历史偏差。

## 本地安装和运行

已有只读输入配置 `graham_inputs/sources.json` 必须存在。安装脚本不下载数据，不写原始市场数据，不覆盖已有不同内容。

```bash
backend/.venv/bin/python scripts/install_dividend.py --original-source strategy/joinquant/红利增强.py
```

当前 `raw/index_daily.parquet` 缺少沪深300的20260731和20260803。已有本地采集文件 `trading_data/experiments/size_regime_20261015/input/000300_SH_20260731_20260803.parquet`，其同目录 `fetch_manifest.json` 记录 index_daily 实际采集及哈希。安装时用 `--index-supplement <该文件绝对路径>` 显式接入；只合并实际记录，同键冲突中止，不插值或前填。补录哈希：`095e075da708e9a301dd3aac66216a05e7939a24760e3c919b5a9455c1dec276`。

在策略回测选择日频本地版本，点击“使用红利日频基线·100万·5只”，选择有完整输入的区间。股票、共用资金、5个持仓、等权、买卖次日开盘、关闭分钟细化和额外环境过滤。额外筛选、退出、评分、风控覆盖会明确拒绝，不会静默忽略。费用可显式改变并随配置保存，不允许自动寻优。
