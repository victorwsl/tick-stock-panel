# 聚宽小市值：核心思路与本地复现

原文件：`strategy/joinquant/小市值.py`。Panel自定义策略ID：`custom_joinquant_smallcap`，名称“聚宽小市值20—30亿〔五日轮换〕”。

## 核心思路

在总市值20亿至30亿元中，由小到大选3只，每5个市场交易日先全部卖出、再买入。仍然入选也卖出重买；卖不掉的仓位继续占用名额和资金，买单不能成交不去追买第四名。它押注小盘股整体及轮换收益，不包含成长、盈利、行业趋势、ST排除或止损逻辑。原文“每天买入”是注释，实际按`g.days % 5`运行。

原代码`run_daily(..., 'every_bar')`会受聚宽回测频率影响，文件没有记录该配置。本地明确采用日频，不把日线版本称为已核实的聚宽原始逐笔结果。

## 在Panel查看

1. 刷新Panel，打开“回测 → 策略回测”，选择该策略。
2. 点击“使用聚宽基线·100万·3只”：共用资金、本金100万、最大3只、等额分配、日线及次日开盘、不择时、不附加止损和评分。
3. 默认调仓锚点2023-01-04，此后每5个市场交易日调仓，改变回测窗口不会重置节拍。若要对照另一份从特定日期启动的聚宽结果，把锚点改为其首次调仓交易日；必须有前一交易日数据。
4. “回测历史”恢复已完成的运行，查看账户曲线、回撤和逐笔清单。点开交易，查看前收市值、排名、信号日和实际成交日、“五日周期清仓”原因。仍入选卖出再买的两个标记会在同一天分别显示。

## 时间与成本口径

| 项目 | 原代码 | 本地适配 |
|---|---|---|
| 市值 | `get_fundamentals`未显式指定日期 | 只读前一市场交易日daily_basic.total_mv，万元乘10000，20—30亿元含边界 |
| 股票池 | 平台估值库 | 历史沪深证券及上市/退市日期；不拿当前存续名单反筛过去；不加财务、ST、新股排除 |
| 计时 | 从策略启动日计5次回调 | 从显式锚点起每5个交易日，避免缩短窗口改变节拍 |
| 停牌 | 当时paused快照 | 缺开盘或开盘非正数作为停牌代理，排序后过滤代理再取前三；缺行情和真实停牌仍未完全分离 |
| 成交 | 聚宽撮合，量比例1 | 开盘涨停不买、跌停不卖，不看随后是否开板；买卖受信号日前最多20条行情均成交额1%限制，首20日用已有前缀，不足容量留现金／持仓 |
| 未成交 | 当日单，下一周期重发 | 当日取消，下一调仓周期再尝试；不会改成每日卖出重试 |
| 资金 | 卖出后按空名额分现金 | 同一现金账本，先卖后买，保留未卖出及待上市股数，禁止透支 |
| 费用 | 佣金万三，卖出税千一，最低5元 | 基线保留上述费率；另计历史过户费、10bp滑点；页面可显式改变成本情景 |
| 公司行动 | 平台处理 | 原始价成交、现金/股数权益账本、20%永久税费准备金；无法解释的调整、分红或持仓退市缺回收账本时报错 |
| 基准 | 沪深300 | 同指数；本地缺日期保持缺失，不补零。曲线按首个可见收盘归一，首日开盘策略与收盘基准时点差异明确披露 |

当日最高、最低、收盘和全日成交量不能参与开盘选股、下单数量及涨跌停判断。收盘仅用于盘后净值估值。未来财报完全不参与本策略。盘后扫描只提供前收市值观察候选，下一开盘过滤停牌代理后才形成最终买入名单，不伪造提前成交事件。

## 可复现与验收

在Panel根目录：

```bash
backend/.venv/bin/python scripts/install_joinquant.py
NUMBA_CACHE_DIR=/private/tmp/graham-numba backend/.venv/bin/python -m pytest -p no:cacheprovider backend/tests/test_personal_joinquant.py backend/tests/test_personal_graham.py backend/tests/backtest/test_strategy_backtest_correctness.py -q
```

安装仅限隔离的`PERSONAL_LOCAL_ONLY`，沿用已经登记的只读历史输入`DATA_DIR/graham_inputs/sources.json`；遇到不同策略文件拒绝覆盖。回测不联网、不更新原始数据。核心改动属于L3小范围接线：复用已有组合账本，增加五日清仓分支；没有复制通用撮合器或建立新平台。新增输入仍走本地研究服务，API不直接读供应商文件。

已验证：市值单位及边界、不额外过滤ST、前一交易日对齐、五日节拍、同票卖后重买、停牌代理递补而涨停不递补、卖不出占位、次日不额外重试、共享资金守恒、未来数据改写及前缀截断前后成交一致、缺历史容量拒单。原Graham与通用回测回归同时通过。

每次运行在`DATA_DIR/research/joinquant_smallcap/<run_id>/`新建目录，包含输入/代码SHA256、冻结规则、完整候选排名、订单、实际成交、拒单、现金账本、逐日持仓和净值、交易CSV，以及自包含`report.html`。Panel完整结果另存在`backtest_history/<history_id>/`，回放图读取当前本地行情，行情修订后可能变化；已保存的交易与账户曲线不会重算。

单股汇总是累计净盈亏除以累计分摊成本，不是单股复利收益；已平仓指标按实际卖出批次，期末未平仓只估值。高收益与小回撤必须由更长历史和新数据检验，当前数据已看过，不能重新称为未见样本外。


## 数据核验记录：2026-10-18

首次2024年以来回测在`300780.SZ / 20240625`被“无法解释的复权变化”守卫中止，没有保存成成功历史。进一步向已配置Tushare接口核验：原快照该日因子`1.0322`，供应商同日返回`1.032`，分红实施表没有该日事件。已登记一行独立更正，附供应商原始响应和原快照SHA256，保存在`DATA_DIR/joinquant_inputs/`；未覆盖原始快照，也未改历史市值。

更正仅对原始值精确匹配时生效，纳入每次输入哈希；不通过容差忽略公司行动，也不根据未来收益反推。该更正属于修订后历史数据研究，不能声称持有当年原始数据版本。Panel复权K线仍来自已有图表数据，这一历史日期可能与更正后权益账本有微小差异，原始成交价和冻结交易记录可独立核对。

本次验证共36项后端测试、4项回放组件测试，完整TypeScript检查与Vite生产构建通过。自动浏览器缺可用运行程序，页面视觉仍未验收。未提交或推送源码。


后续发现不是单行问题：多个日期存在复权精度／修订差异。按冻结规则和开盘停牌代理先确定完整研究区间可能买入的308只证券，独立向供应商取回278,463条历史复权，逐键与原快照比较，登记13,205行差异；未按交易盈亏筛核验对象。完整响应、差异表及manifest在`joinquant_inputs/`；每次回测另存实际使用的更正表。原始价和历史市值没有改变，股票没有因数据困难被删除。核验覆盖当前2024年以来配置的证券，扩展区间可能需要再次核验，遇到新异常仍报错。
