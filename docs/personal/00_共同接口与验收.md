# 因子检验与交易回测：共同接口与验收

2026-10-18。配合[系统与策略方案](07_轻量量化工作台_Agent施工方案.md)及[回测验收](02_交易回测施工说明.md)执行。目标：指标可追溯、成交可解释、输入不变则结果可复现。

## 1. 模块边界

- 采集层更新原始数据；研究读取本地冻结数据，不在回测循环中联网。
- 因子层负责特征、标签、完整候选和排名；执行层消费这些结果，不悄悄重算排名。
- 界面展示实验、账本和复盘；不承担另一套计算口径。
- 同时工作的Agent不能编辑同一文件。默认不开子Agent；不覆盖已有修改，不自动发布、通知、导出或操作真实账户。

## 2. 数据和时间

- 只由采集层访问 Tushare。研究及回测读取 `SLQUANT_DATA_ROOT` 下本地数据，不在逐日回测循环中联网。
- 日历使用交易所日历，时间使用 Asia/Shanghai。保留信号产生时间与最早可执行时间。
- T 日收盘产生信号，最早 T+1 开盘执行。开盘决策不能读取当天收盘价、最高价、最低价或全日成交量。
- 日线能否真实排到涨跌停队列无法精确知道，必须明确保守撮合假设，并单列敏感性结果。
- 财务数据按公告可得时间进入；只有公告日期、没有时刻时，保守从下一交易日可用。若有经核实的时刻，可按时刻处理。历史修订值没有 vintage 时必须披露，不宣称严格历史可得。
- 股票池用历史上市、退市和状态数据，不能只读当前存续股票。缺少资料则缩小结论范围并披露偏差。
- 原始价用于成交和现金账；复权/总回报口径用于跨除权收益比较，必须有明确映射，不能把复权价与真实股数混算。
- 保留缺失原因：未上市、停牌、数据缺失、标签未成熟、因子无足够历史。不能全部填零，也不能根据未来是否有完整报价提前剔除候选。

## 3. 冻结交付包

所有表使用 Parquet；小型汇总另输出 CSV。股票标识统一 `ts_code`，日期统一 YYYYMMDD，主键唯一。因子和未来结果物理分文件存放。

| 文件 | 必要字段/内容 |
|---|---|
| `factors/<factor_id>.parquet` | `trade_date, ts_code, factor`；可得时间与公式写入 spec |
| `candidates.parquet` | `trade_date, ts_code, baseline_score`；多路命中用独立 provenance 表保留，组合内一个股票只占一个名额 |
| `ranked_candidates.parquet` | `trade_date, ts_code, variant_id, score, rank`；包含所有当日候选，另列因子贡献和缺失标记 |
| `labels.parquet` | 信号键、计划/实际入场日期、终点日期、H、收益、基准收益、有效标记和无效原因；绝不提供给选股代码 |
| `resolved_spec.json` | 股票池、时点、公式、方向、归一化范围、并列规则、缺失政策、费用、价格和基准口径 |
| `manifest.json` | 数据截止日、输入输出 SHA256、命令、随机种子、Git commit、相关脏文件内容哈希或补丁、Python 与依赖版本、运行状态 |

这些是后续完整实验的验收合同；当前v0信号CSV使用ISO日期及`date/symbol`，对接时须显式映射，不假装已具备完整交付包。当前manifest尚缺完整输入哈希与环境记录，下一阶段补齐。

每个运行目录不可覆盖。执行层必须记录它消费的交付包哈希；没有匹配哈希的两份报告不能声称是同一实验。

## 4. 标签的精确定义

主口径：T 收盘信号；计划入场为交易所下一交易日开盘；H 日终点为 T 之后第 H 个交易所交易日收盘，H=1 即下一交易日收盘。无开盘报价不能当作零收益。主诊断标签入场不可得时记无效，不顺延终点，不用未来可成交性过滤信号。

若额外研究“等待到下一可交易日再买”，必须用另一标签版本，明确等待上限与终点是否移动。真实交易由订单有效期决定等待或撤单，不反向改变已生成的因子排名。历史 `attach_outcomes` 如果语义不同，输出差异表、版本化修正，不静默覆盖原实验。

基准与股票使用相同起止时点。基准缺行情标缺失，不自动填零。MAE/MFE 只用入场到终点的价格；日内高低用于事后诊断，不能进入当时决策。

## 5. 所有报告都必须说明

1. 哪些是实际运行结果、哪些是计划、哪些因数据不足未运行。
2. 有效日期数、有效股票数、剔除和缺失数量、实际覆盖区间。
3. 价格/复权口径、信号与成交时点、费用和基准口径。
4. 核心结论、反例与限制；不能将因子相关性写成重仓盈利保证。
5. 可复现命令、数据/代码版本、机器可读明细和单文件 HTML。HTML 内联样式、图表资源，手机能横向滚动表格。

正确性必须先通过手算样例、时间截断测试和账本检查，再跑历史全量。库能运行或图好看不构成通过验收。
